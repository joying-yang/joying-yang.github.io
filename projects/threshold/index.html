Threshold

Experience design · Front-end engineeringWebGL · TypeScript · Accessibility · Motion

A spatial archive that turns a dense collection into a calm, explorable narrative without sacrificing keyboard access.

Context

Context

Digital archives are usually optimized for storage, not orientation. Threshold asks how a collection can feel like a place while remaining fast, readable, and inclusive.

Constraints

Constraints

  • Content had to remain available before the visual layer loaded.
  • Navigation needed to work with keyboard, touch, and reduced motion.
  • The scene had to remain stable on mid-range mobile hardware.

Role

Role

Experience design · Front-end engineering

Key decisions

Key decisions

  • Kept semantic HTML as the canonical content source.
  • Authored deterministic camera poses instead of free-roaming controls.
  • Built depth from shared line geometry and a restrained two-color system.

Process

Process

Mapped the semantic reading path first, proved two spatial stops as a vertical slice, then tuned motion and quality tiers on narrow and wide viewports.

Result

The final prototype preserves the atmosphere of a spatial gallery while every core path remains available in a focused 2D presentation.
